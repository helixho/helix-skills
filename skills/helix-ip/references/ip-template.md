# IP.md 模板

每个品牌一份，只写当前结果。括号内是填写要求，交付时删除括号说明。

```markdown
# {品牌名}

## 事实

- 主体：（个人 / 公司，正式名称与对外显示名）
- 业务：（提供什么，一句话）
- 服务对象：（谁会付费或使用）
- 经历与资质：（可核实的条目；没有就不写）
- 联系方式：（对外公开的渠道）
- 公开边界：（不能对外出现的名称、客户、数据、地址等）

## 定位

- 目标受众：
- 类别：（别人会把它归到哪一类）
- 要解决的问题：
- 替代方案：（受众现在用什么解决，至少 1 条，互不重复）
- 差异化价值：
- 承诺：（受众得到的结果；不能只是重复差异化价值）
- 支撑理由：（至少 1 条，每条都能在"事实"里找到依据）
- 边界：（不做什么、不承诺什么，至少 1 条）

## 口径

- 名称写法：（中文、英文、简称、何时用全名）
- 声音原则：（至少 3 条）
- 场合语气：（至少 2 种场合，例如首页、合作邀请、技术说明）
- 信息层级：（先说什么、再说什么，至少 2 层）
- 常用词：（至少 3 个）
- 避免词：（至少 3 个）
- 中英文规则：（标点、大小写、并置方式）
- 示例：（至少 2 句真实可用的文案；要用到常用词，不出现避免词）

## 视觉方向

- 方向：（一句话）
- 要：（2–3 条）
- 不要：（2–3 条）
- 设计系统：（名称或链接；Logo、颜色、字体、组件以它为准）

## 待确认

- （问题）——影响：（事实 / 定位 / 口径 / 视觉方向中的哪一项）
```
