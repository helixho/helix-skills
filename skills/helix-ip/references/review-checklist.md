# 审查清单

## IP.md 自检

**完整**

- 模板中的每一项都有内容，或明确写了"无"并说明原因。
- 数量要求达标：替代方案、支撑理由、边界 ≥1；声音原则、常用词、避免词 ≥3；场合语气、信息层级、示例 ≥2；视觉方向的"要"和"不要"各 2–3 条。

**一致**

- 承诺没有重复差异化价值。
- 每条支撑理由都能在"事实"里找到依据。
- 替代方案、边界各自没有重复项。
- 示例用到了至少一个常用词，且没有出现避免词。
- 视觉方向只有一个选定方向。

**事实**

- 正文里没有未确认的内容；推测、缺失信息都在"待确认"里。
- 没有编造的客户、数据、奖项、雇主、日期、资质或成果。
- 公开边界里列出的内容没有出现在其他部分。

**干净**

- 没有过程、版本、审批、讨论记录。
- 没有 Logo 设计意图、变体、主稿来源等设计产物信息。

## 对外产物审查

适用于设计系统、网站、页面、演示文稿、社交图片等。

- **名称**：品牌名、中英文写法与"口径 · 名称写法"一致。
- **事实**：出现的每个事实性说法（经历、数据、客户、资质）都能在"事实"里找到；公开边界里的内容没有出现。
- **定位**：首屏或开头传达的受众、问题、价值与"定位"一致，没有承诺边界之外的事。
- **口径**：语气符合对应场合；没有避免词；信息先后顺序符合信息层级。
- **视觉**：整体方向符合"视觉方向"；没有命中"不要"里的任何一条。
- **设计系统引用**：页面使用的 Logo、颜色、字体来自"视觉方向 · 设计系统"指定的设计系统。
