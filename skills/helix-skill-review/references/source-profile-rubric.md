# Source Profile Rubric

Evaluate a Git-acquired upstream source project as a system. This profile
complements but never overwrites individual Skill Scorecard results. Local packs
and application-origin bundles are not eligible for a Source Profile.

| Dimension | 1 | 3 | 5 |
|---|---|---|---|
| System coherence | Isolated fragments | Related skills with partial links | Deliberate, navigable capability system |
| Internal dependency value | Skills stand alone | Some useful sharing | Meaningful cross-skill resources, vocabulary, or runtime |
| Learning value | Little reusable insight | Several useful patterns | High-value system patterns worth studying intact |
| Operational health | Broken or opaque project | Usable with caveats | Clear boundaries, maintenance, and source-native operation |
| Library fit | No useful role | Reference-only niche | Clear role in the library or study portfolio |

## Classification

- `whole-project-preserve`: retain and assess as a system; do not infer a
  lifecycle recommendation from a low individual score.
- `study-first`: preserve the source as a reference; use only selected patterns.
- `standalone-friendly`: individual skills can normally be compared or deployed independently.
- `source-review-needed`: source-level health or provenance needs review.

Profiles are advisory. They never authorize deletion, deployment, source edits,
or score reweighting.
