# 谬误清单

审查论述类内容时逐一对照。每条给出识别特征和修正方向；报告问题时写明谬误名称。

## 形式谬误：推理形式无效

| 谬误 | 识别特征 | 修正方向 |
|---|---|---|
| 肯定后件 | 若 A 则 B；B 成立，所以 A 成立 | 补出排除 B 的其他成因的依据，或把结论降为“可能” |
| 否定前件 | 若 A 则 B；A 不成立，所以 B 不成立 | 指出 B 可能另有成因，改为条件更完整的推理 |
| 中项不周延 | 两个对象都具有某属性，就推出二者相同或相关 | 补出二者直接相关的依据 |
| 四概念 | 三段论中，中项在两个前提里含义不同，推理靠这个词连接 | 统一定义后重新检验推理（对应同一律） |

## 相关性谬误：依据与结论无关

| 谬误 | 识别特征 | 修正方向 |
|---|---|---|
| 稻草人 | 反驳的是被歪曲、简化或夸大后的对方主张 | 复述对方的真实主张，再针对它论证 |
| 诉诸人身 | 用对方的身份、动机或品格否定其观点 | 只评价观点本身的依据 |
| 诉诸权威 | 仅凭某人或某机构的身份认定结论成立，不给理由 | 给出权威所依据的理由或证据，并说明其适用范围 |
| 诉诸大众 | 因为很多人认同或这样做，就认定正确 | 给出与结论直接相关的依据 |
| 诉诸情感 | 用恐惧、同情、愤怒等情绪代替理由 | 把情绪背后的事实和推理写出来 |
| 诉诸传统或新颖 | 因为一贯如此或因为新，就认定更好 | 比较两种做法在目标上的实际效果 |
| 转移话题 | 回应偏离原问题，引入另一个议题 | 回到原问题，另一个议题单独讨论 |
| 诉诸无知 | 没被证明错就当成对，或没被证明对就当成错 | 把结论写成“尚无依据”，不当作已证实或已证伪 |

## 预设与证据谬误：前提有问题

| 谬误 | 识别特征 | 修正方向 |
|---|---|---|
| 循环论证 | 前提里已经预设了结论 | 给出独立于结论的依据 |
| 复杂问句 | 问题本身预设了一个未经确认的前提 | 先单独确认这个前提 |
| 虚假两难 | 只给两个选项，漏掉其他合理做法（包括不做） | 列出所有合理选项（对应划分规则） |
| 以偏概全 | 由少数个例推出普遍结论 | 收窄结论范围，或补充更有代表性的依据 |
| 片面取证 | 只引用支持结论的证据，回避相反证据 | 列出相反证据并说明为何结论仍成立 |
| 举证责任倒置 | 要求对方证明自己的主张不成立 | 由提出主张的一方给出依据 |

## 因果谬误：因果关系不成立

| 谬误 | 识别特征 | 修正方向 |
|---|---|---|
| 滑坡 | 把一连串可能的后果说成必然发生，每一步缺少依据 | 逐步给出依据，或把结论降为“可能” |
| 事后归因 | 因为 B 发生在 A 之后，就认定 A 导致 B | 排除其他原因，或改为“先后发生” |
| 相关当因果 | 两者同时变化，就认定一方导致另一方 | 排除共同原因和反向因果 |
| 因果倒置 | 把结果当成原因 | 核对时间顺序和作用方向 |
| 单一原因 | 把多因素造成的结果归于一个原因 | 列出其他主要因素及其作用 |

## 歧义与类比谬误：表述导致推理失真

| 谬误 | 识别特征 | 修正方向 |
|---|---|---|
| 偷换概念 | 论述过程中悄悄改变了关键词的含义或范围 | 统一定义（对应同一律） |
| 合成谬误 | 部分具有某性质，就推出整体也具有 | 补出整体层面的依据 |
| 分割谬误 | 整体具有某性质，就推出每个部分也具有 | 补出部分层面的依据 |
| 不当类比 | 用相似点推出结论，忽略关键差异 | 说明关键差异不影响结论，否则放弃这一类比 |
| 断章取义 | 引用脱离原文语境，改变了原意 | 补全语境后重新引用 |
