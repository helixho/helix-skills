# 谬误辨析

本表提供论证的成立条件与修正方向，不按关键词定罪，也不把一切论证都视为演绎证明。一个问题可能涉及多个名称，合并报告同一缺陷。规则、定义、缺失和信息价值的通用判据见 [审查正文](../SKILL.md)。

## 形式推理

| 何时构成 | 相似但不构成 | 怎么修正 |
|---|---|---|
| **肯定后件**：仅由 A→B 和 B 推出 A 必然成立。 | 已有 B→A 的独立依据，或明确给出等价关系；有相应证据的暂定解释也不同于必然推导。 | 指出缺少反向关系，收回必然结论；只有已有依据才能补入前提。仅加“可能”不能补足证据。 |
| **否定前件**：仅由 A→B 和非 A 推出非 B。 | 已给出 B→A，或有其他排除 B 的充分依据。 | 说明 B 仍可能由其他条件成立；保留能推出的结论，不虚构“只有 A 才 B”。 |
| **中项不周延**：三段论的中项在两个前提中都没有指其全体，不能连接另外两项；如“所有 A 都是 C，所有 B 都是 C，所以所有 A 都是 B”。 | 有能连接两类的额外包含关系，如“所有 A 都是 C，所有 C 都是 B”。 | 展示共享类别为何不足以推出所声称关系；补关系须有依据，否则撤回推论。 |
| **四概念**：三段论表面只有三个概念，实际因换义等原因出现了第四个，连接因此中断。 | 明确对应的别名仍指同一概念；本就不是三段论的论证也不以术语数量判错。 | 统一实际含义后重新检查推理，不只是把字面词语改成一样。 |

## 相关性与来源

| 何时构成 | 相似但不构成 | 怎么修正 |
|---|---|---|
| **稻草人**：把对方主张改成其未主张的、更容易反驳的版本，再声称反驳了原观点。 | 忠实概括，或明确说明正在讨论一个假设、变体或后果。 | 对照原观点及限定，修复被替换的主张后再评价。 |
| **诉诸人身**：用与论证无关的身份、动机或品格，代替对主张及依据的评价。 | 评价证言或来源可靠性时，相关的利益冲突、资质或既往可靠性可以是证据。 | 说明被引用的个人信息与当前推理有何关系；无关的移除，不能以动机直接证明结论为假。 |
| **不当诉诸权威**：把无关领域、缺乏可信依据的权威身份当作充分证明，或忽略已知的相关分歧。 | 在相关专业范围内，可信来源和适当证据可以支持有限结论，不要求每次重述全部原始证明。 | 核对专业范围、依据、可信度和相关反证；“专家说”或附上一句“因为”都不自动决定论证好坏。 |
| **诉诸大众**：仅凭很多人相信或采用某做法，就认定它客观正确或应当采用。 | 结论本来就是支持率、流行程度，或明确采用多数票的决策规则。 | 区分关于人数的事实与关于真伪、效果或应然的结论，补相应依据。 |
| **诉诸情感**：把恐惧、同情等反应当成无关事实主张的证据。 | 当目标本身涉及情感体验或价值取舍时，情感可以是相关考虑；表达情感不等于提出论证。 | 写明情感与主张之间的实际关系；不能用情绪代替所需事实或推理。 |
| **诉诸传统或新颖**：仅因一贯如此或做法新，就认定正确或更好。 | 长期经验有可检验的效果依据，或新颖性本身是已明确的目标。 | 比较与目标相关的依据，不能仅替换为“传统不好”或“新颖不好”。 |
| **转移话题**：用没有回答原问题的另一主张，充当对原问题的回应。 | 与原问题有明确关系的背景、必要前提或已同意的范围调整。 | 明确原问题和回答之间缺少的联系，补回回答或注明另议。 |
| **诉诸无知**：未证明为假就断言为真，或未证明为真就断言为假。 | 在有明确覆盖范围与检出能力的检查中，未发现可以构成有限的负面证据；陈述“尚未发现”本身不越界。 | 写明查到与未查到什么、检查能支持的范围；未知不直接变成确定结论。 |

## 前提与证据

| 何时构成 | 相似但不构成 | 怎么修正 |
|---|---|---|
| **循环论证**：支持结论的理由直接或间接预设了待证明的结论，没有独立支持。 | 重述结论作摘要，或按双方接受的前提推导，不因出现相同词语就循环。 | 指出依赖环，寻找材料中已有的独立依据；没有时收回“已证明”的说法。 |
| **复杂问句**：提问把尚未接受的争议前提当成已成立，使直接回答被迫承认它。 | 前提已给定、已被接受或问题明确标为条件假设。 | 拆开前提是否成立与后续问题，不迫使对方先承认争议事实。 |
| **虚假两难**：声称只能选所列方案，实际遗漏当前范围内仍可行且未被排除的选项。 | 真实穷尽的两种情况，或用户已明确限定选择范围。 | 指出具体遗漏及其可行依据；包括仍可行的“不做或维持现状”，不机械加入已排除项。 |
| **以偏概全**：把有限或有偏样本推广到其不足以支持的总体或确定程度。 | 有适当条件与不确定性说明的样本估计，或结论只描述被观察的样本。 | 收窄范围和强度，或说明需要怎样的代表性证据；不要求经验判断达到演绎确定性。 |
| **片面取证**：忽略材料中已知且相关的相反证据，使支持程度被夸大。 | 与问题无关的材料未纳入，或作者已解释相反证据及其权重。 | 列出遗漏的相关证据，重新评价支持强度；不凭想象断言存在反证。 |
| **举证责任倒置**：主张尚无充分支持，却要求别人先证明它不成立，以此要求接受主张。 | 按已明确的证明责任、程序或共同约定，要求对应方提供所需依据。 | 还原各方实际主张与承担的证明责任，不把对方无法反驳当作支持证据。 |

## 因果与解释

| 何时构成 | 相似但不构成 | 怎么修正 |
|---|---|---|
| **滑坡**：把缺乏支持的一串后果说成必然或高度可信，并靠这一链条推出结论。 | 对关键环节有依据、说明条件与不确定性的风险分析。 | 检查每个关键连接及整体强度；可据证据减弱结论，不能只加“可能”保留无依据的整条链。 |
| **事后归因**：仅因 B 在 A 之后发生，就断言 A 导致 B。 | 时间顺序之外还有与问题相称的对照、机制或其他因果证据。 | 保留先后观察，指出因果依据缺口；缺少支持时将解释标为待检验假设。 |
| **相关当因果**：仅因 A、B 共同变化，就断言特定因果关系。 | 相关性与适当设计、机制、条件控制或其他证据共同支持因果主张。 | 检查关键共同原因和反向解释；依据应与主张强度相称，不要求排除一切可想象因素。 |
| **因果倒置**：声称的方向与给定证据支持的方向相反。 | 双向作用有依据；方向未知时也不能直接认定“反过来才对”。 | 有反向证据时说明它；只有相关性时报告方向依据不足，不擅自翻转因果。 |
| **单一原因**：把不足以单独解释结果的一个因素，声称为唯一或充分原因，忽略已知的关键共同条件。 | 明确只分析一个因素的作用，或在其他条件已限定时讨论它。 | 按已有材料补明共同条件、贡献范围或证据缺口，不罗列无依据的所有可能因素。 |

## 含义、部分整体与类比

| 何时构成 | 相似但不构成 | 怎么修正 |
|---|---|---|
| **偷换概念**：推理过程中，同一关键词的含义或范围变化，结论却依赖它始终同义。 | 明确区分不同用法，或已定义的同义词、全称与简称。 | 标明变化发生在哪里，统一实际概念后检查结论还能否成立。 |
| **合成谬误**：没有相应依据就把部分的性质转给整体。 | 该性质按给定关系确实能由部分传到整体。 | 指出缺少的整体关系或条件；不把“部分如此”直接写成“整体如此”。 |
| **分割谬误**：没有相应依据就把整体的性质分配给每个部分。 | 已有性质可以分配到各部分的依据。 | 区分整体指标与个体性质，补相应依据或收回个体断言。 |
| **不当类比**：根据表面相似推断目标性质，却忽略影响该性质的关键差异。 | 类比仅用于说明，或相似点与目标性质确有联系且差异已恰当处理。 | 说明哪些相似点支持迁移、哪些差异限制它；不要求对象在所有方面相同。 |
| **断章取义**：删去或改变语境，使引用呈现的主张不同于原意。 | 保留原意与必要限定的摘要、节选或转述。 | 补回会改变含义的上下文，区分原话、转述和自己的推断。 |
